# 设计令牌

面板、面板插件、扩展页面与主题共用的一套 CSS 变量。**颜色、圆角、间距一律从这里取，不要写死色值** —— 写死的那个在另一款主题、另一种明暗下可能看不见，而用令牌写的换了主题自动跟着变。

这些变量是**公开契约**：只增不改名。数值随主题与明暗变化，下表给的是经典主题的取值，仅作参考。

## 在哪里能用

| 写的是 | 怎么用 |
|---|---|
| 面板插件（组件、页签） | 直接写 `var(--text)`，行内样式与自带样式表都行，见[面板插件 · 样式](/panel-plugin#样式) |
| 扩展页面 | 页面里引一行 `<script src="/theme-sdk.js"></script>`，这些变量就写到页面根上了，见[扩展页面 · 跟着主题走](/custom-page#跟着主题走) |
| 主题 | 在样式表里重新声明它们，见[主题开发](/theme-dev#样式表) |

明暗的判据是 `<html data-scheme="light|dark">`，不是 `prefers-color-scheme`。

## 颜色

| 变量 | 含义 | 经典 · 浅 | 经典 · 深 |
|---|---|---|---|
| `--bg` | 页面底色 | `#f0f2f5` | `#0f1117` |
| `--panel` | 卡片面 | `#ffffff` | `#1a1d27` |
| `--raise` | 抬起一层（输入框、表头、悬停底） | `#f6f8fa` | `#232733` |
| `--border` | 描边 | `#e4e8ed` | `#2d3348` |
| `--border-strong` | 加重的描边（开关轨道、分隔） | `#cdd3dc` | `#3d4460` |
| `--text` | 正文 | `#1e2128` | `#e8eaf0` |
| `--muted` | 次要文字 | `#6b7280` | `#8b92a5` |
| `--accent` | 强调色（文字、描边用） | 由 `--accent-hue` 推出 | 同左，提亮 |
| `--accent-solid` | 强调色（填充用：主按钮、开关、进度） | 同上 | 同上 |
| `--on-accent` | 压在 `--accent-solid` 上的字 | `#ffffff` | `#ffffff` |
| `--accent-glow` | 强调色的淡光（焦点环、选中外圈） | 半透明 | 半透明 |
| `--accent-2` | 辅色：渐变与图表的第二支颜色 | 主色相偏 40° | 同左 |
| `--accent-hue` | 强调色的色相，外观页改的就是它 | `239` | `239` |
| `--ok` / `--warn` / `--err` | 成功 / 警告 / 错误，只用于表达状态 | 绿 / 琥珀 / 红 | 提亮 |
| `--info` | 与状态无关的提示，**不要当主色用** | 蓝 | 提亮 |
| `--on-err` | 压在 `--err` 上的字（危险按钮） | `#ffffff` | 深字 |
| `--code-bg` | 代码与等宽块的底 | `#f8f9fc` | `#151820` |
| `--scrim` | 模态与抽屉背后的遮罩 | 半透明黑 | 更深 |
| `--scrollbar-thumb` / `--scrollbar-thumb-hover` | 滚动条滑块 | 跟着强调色 | 同左 |
| `--fg` / `--line` | 旧名，分别等于 `--text` / `--border` | | |

## 字体与字号

| 变量 | 含义 |
|---|---|
| `--font-ui` | 界面字族 |
| `--font-mono` | 等宽字族：机器产出的值（版本号、路径、时间）一律用它 |
| `--fs-h1` / `--fs-h2` / `--fs-h3` | 标题，22 / 16 / 13.5px |
| `--fs-body` | 正文，14px |
| `--fs-hint` / `--fs-label` | 说明文字 / 标签，12.5 / 11.5px |

字号随外观页的「字号」档位整体缩放。

## 间距与圆角

| 变量 | 含义 |
|---|---|
| `--s1` … `--s8` | 间距梯级，4 / 8 / 12 / 16 / 20 / 24 / 32 / 48px，随「密度」档位缩放 |
| `--r-card` | 卡片圆角，14px |
| `--r-ctl` | 控件圆角（按钮、输入框），10px |
| `--r-pill` | 药丸与徽标，`999px` |

## 投影与动效

| 变量 | 含义 |
|---|---|
| `--shadow-float` | **唯一一档投影**，只给浮起之物：拖动中的格子、下拉菜单、模态、提示条。页面平面之内的东西（卡片、输入框）不用投影 |
| `--shadow-sm` … `--shadow-2xl` | 旧名，保留给已经在用的插件，大的几档等于 `--shadow-float`、小的几档为无 |
| `--dur-1` / `--dur-2` / `--dur-3` | 过渡时长：控件变色 / 一般位移 / 大面积表面，150 / 250 / 350ms，随「动效」档位缩短或关闭 |
| `--ease` | 标准缓动 |

只过渡 `transform`、`opacity`、`color`、`background-color`、`border-color`；不要过渡 `width`、`height`、`top`、`left` —— 它们逐帧重排，在手机上表现为卡顿。

## 槽位变量

主题给了某个[槽位](/theme-dev#槽位)时，面板还会写一组 `--slot-*` 变量（如 `--slot-empty`、`--slot-frame-card`），并在 `<html data-slots>` 里列出槽位名。插件一般不必读它们 —— 面板插件用 `api.theme.asset("empty")`，扩展页用 SDK 的 `yzng:theme` 事件。

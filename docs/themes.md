# 外观与主题

面板的「外观」页管三件互不相干的事：

| | 是什么 | 例子 |
|---|---|---|
| **主题** | 一整身皮肤：配色、字体、导航图标、卡片边框、开关的贴图、插图、背景 | 经典、YUNZAI NG、商店里装来的角色主题 |
| **明暗** | 跟随系统 / 浅色 / 深色 | 夜里切到深色 |
| **个人偏好** | 密度、字号、内容宽度、动效、低功耗 | 视力不好调大字号 |

换主题不动明暗，换明暗不动主题；个人偏好跟着人走，换哪款主题都保留。

## 换主题

外观页 → **主题**页签，点一张卡片即换，立即生效、不用刷新。

- **经典**：新装默认。云蓝与云青来自品牌图标的云和光环，浅色是蓝白底、深色是靛蓝底；强调色仍可随意调。别的主题没写到的地方都从经典取，所以它也是兜底层。
- **YUNZAI NG**：按新品牌图标的南瓜黄橙红、云与光环青蓝紫配色，浅色蓝白底、深色靛蓝底。主按钮与页签用黄橙红，模态上沿与背景用青蓝紫；导航图标、开关、空状态、登录插图与预览一起更新。一整套南瓜导航图标；开关的滑块是一只南瓜，关着时睡着、拨开时醒来笑并撒出一把南瓜籽，拨关时落下两片叶子（模态里的开关也一样）；鼠标停在插件页、插件市场、面板商店的卡片或概览页的组件格子上时，卡片朝鼠标微微倾斜（编辑版面时不倾斜）；概览页每一格的格缝里长出一棵芽；空状态是一只抬头看云的南瓜；登录页卡片顶上是南瓜田（浅色是清晨，深色是夜里亮着的南瓜灯）；日志页做成终端框；圆体拉丁字。强调色定死，圆角与背景可调。

更多主题在**面板商店**的「主题」栏，装法与组件一样，见[安装与管理插件](/install-plugins#从面板商店装面板插件)。装完回到外观页就能选。

主题换的不只是面板自己：面板插件的组件、插件页的页签、各插件的扩展页面也一起跟着换，前提是那些插件按[设计令牌](/design-tokens)写颜色 —— 官方插件都是这么写的。

::: tip 主题能改哪些，由主题决定
主题页签下半部分是「在这款主题之内调整」：强调色、圆角、背景。这些调整**只对当前这款主题生效**，各款分别保存。主题作者可以把某几项锁住（比如配色定死的品牌主题），那一行会置灰并说明原因。
:::

## 明暗

外观页 → **明暗**页签，或侧栏底部那枚按钮（每点一次在「跟随系统 → 浅色 → 深色」之间转一格）。

「跟随系统」随操作系统的深浅设置变。有的主题只做了一套（比如只有夜景的主题），那时明暗按钮会置灰，说明「当前主题只有一套明暗」。

## 个人偏好

- **版式**：密度（间距）、字号、内容区最大宽度。
- **动效**：完整 / 减弱 / 关闭；系统设置了「减少动态效果」时始终从简。
- **低功耗**：关掉背景动画、光斑与背景大图，主题自带的动画也会停。**手机与 Termux 上推荐打开。**

这些都存在当前浏览器里，换一台设备要重新设。**备份**页签可以把整份外观配置导出成一个 JSON，到另一台设备上导入。

## 给所有人定一个默认主题

各人选的主题存在各自的浏览器里。管理员想让「还没选过」的人默认看到某一款，在面板的**配置**页（webui 那一组）填「站点默认主题」，填主题 id（外观页卡片上可见，如 `pumpkin`）。已经选过的人不受影响。

## 主题把页面弄坏了

第三方主题写坏了，可能把外观页本身遮住、点不到东西。这时在面板地址后加 `?theme=safe` 打开：

```
http://127.0.0.1:2536/?theme=safe
```

安全模式下不加载任何主题、不跑任何主题脚本，面板是经典的样子。进外观页换回别的主题，再去掉 `?theme=safe` 刷新即可。

## 主题会带脚本

主题可以带一段脚本做更花的效果（比如开关切换时换表情）。脚本跑在面板里，与面板插件**同等信任** —— 它能做面板插件能做的任何事。所以只装你信得过的来源，外观页的主题卡片上会标出「带脚本」。

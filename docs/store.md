# 插件商店

下面这份列表**直接读[插件索引](https://github.com/Yunzai-NG/plugin-index)**渲染，与面板内的插件市场同一来源 —— 索引里上架了什么，这里就有什么。真正的安装、更新、卸载都在面板里操作，本页只用于浏览。

## 想上架自己的插件

发一个 PR 到 [plugin-index](https://github.com/Yunzai-NG/plugin-index) 仓库，往 `index.json`（内核插件）或 `webui_index.json`（面板插件）里加一条即可。字段含义、`minCore` 版本门与校验规则见[插件市场](/market)，写插件本身见[插件开发](/plugin-api)。

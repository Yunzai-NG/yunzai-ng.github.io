# 品牌图标

三种形制，均由 [`tools/brand.ps1`](https://github.com/Yunzai-NG/yunzai-ng/blob/main/tools/brand.ps1)
生成。**不要手改这些 SVG**：几何全部由参数推导，手改会在下一次运行脚本时被覆盖。

| 文件 | 画幅 | 背景 | 用途 |
|---|---|---|---|
| `icon-square.svg` | 1:1 | 炭底圆角方 | favicon、应用图标 |
| `icon-circle.svg` | 1:1 | 炭底圆 | 头像、社群图标 |
| `icon-mark.svg` | 由字形决定 | 无 | 站点页头、README、深浅主题各半的场合 |

`icon-mark.svg` 的填色为 `currentColor`，由使用处的 `color` 决定。深色背景上取
`#f0d8a8`，浅色背景上取 `#7a5c1f` —— 金色压在白底上对比度仅约 1.9:1，不可直接沿用。

## 构图

一个被横向切开的 Y。

```
╲    ╱      两臂  = 插件，次亮（#d3bc8e）
 ╲  ╱
──────      缝    = 「内核不 import 插件」这条由 check:layering 保证的不变量
   ▌        竖干  = 内核，最亮（#f0d8a8），全局唯一不是插件的那一块
```

缝宽等于 V 底边宽，因此缝是一个整齐的矩形负形。V 收拢为一路即 fan-in：多个插件的
消息汇入单一内核管线。Y 指向 Yunzai 一脉；Y 被切开又重新拼起，即「新一代」的声明。

## 为什么是这个构图

关键在**退化方式**。16px 下缝退化为一个物理像素的接痕，最坏情况是看起来就是一个
实心 Y —— 退化后仍在品牌上。此前四版分别退化为横杠、除号、无插件语义的孤立 Y，
以及一团糊掉的椭圆，形与义俱失。

「可插拔」是关系概念，而关系在 16 像素里几乎没有表达空间。因此不往 Y 上挂模块，
只留一处负形，把全部语义压在这一个特征上。

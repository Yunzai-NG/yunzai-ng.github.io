# 品牌图标

## 文件

| 文件 | 底 | 用途 |
|---|---|---|
| `logo-lockup.svg` / `.png` | 透明，灰字橙 NG | 浅色背景上的横版字标：站点页头、README |
| `logo-lockup-ondark.svg` / `.png` | 透明，白字橙 NG | 深色背景上的横版字标 |
| `logo-lockup-light.svg` / `.png` | 透明，单色灰 | 只能用单色的浅色场合 |
| `logo-lockup-dark.svg` / `.png` | 透明，单色白 | 只能用单色的深色场合 |
| `logo-circle.svg` / `.png` / `.webp` | 深色圆 | 头像、社群图标 |
| `logo-square.svg` / `.png` | 深色方 | 需要满幅方图的平台 |
| `logo-rounded.svg` / `.png` | 深色圆角方 | favicon、应用图标 |
| `logo-hexagon.svg` / `.png` | 深色圆角六边形 | 徽章、贴纸 |
| `logo-mark.svg` / `.png` | 透明，彩色 | 只要图形不要字的地方 |
| `logo-mark-light.svg` / `logo-mark-dark.svg` | 透明，单色 | 同上，单色版 |

方形位图边长 1024，字标位图宽 2048。字标的字母是画出来的路径，不依赖字体。

## 构图：YUNZAI NG

```
   ☁☁       云      = 云崽（Yunzai），沿用最初的双层云与云里那道弧
    ↟       瓜蒂、卷须与叶 = 代替原来的内核点：内核从这里长出来、把消息送上云端
  ▭▭▭▭▭     南瓜台  = NG，社区里读作「南瓜」；五瓣对应「一个内核 + 若干插件」
```

彩色版的云带白描边，深浅背景上都能直接用；单色两版对应「白底黑字」与「黑底白字」。

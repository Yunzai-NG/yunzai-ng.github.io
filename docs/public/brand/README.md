# 品牌图标

## 文件

| 文件 | 底 | 用途 |
|---|---|---|
| `logo-mark.png` / `.webp` | 透明，彩色 | 只要图形不要字的地方；`.png` 边长 1024，`.webp` 768 |
| `logo-mark-256.png` | 透明，彩色 | 面板左上角与 favicon（即 webui 的 `logo.png`） |
| `favicon-64.png` | 透明，彩色 | 浏览器标签页 |
| `logo-mark-light.png` / `logo-mark-dark.png` | 透明，单色灰 / 单色白 | 只能用单色的浅色 / 深色场合 |
| `logo-lockup.svg` / `.png` | 透明，深灰字橙 NG | 浅色背景上的横版字标：站点页头、README |
| `logo-lockup-ondark.svg` / `.png` | 透明，白字橙 NG | 深色背景上的横版字标 |
| `logo-lockup-light.svg` / `.png` | 透明，单色灰 | 只能用单色的浅色场合 |
| `logo-lockup-dark.svg` / `.png` | 透明，单色白 | 只能用单色的深色场合 |
| `logo-square.png` | 白方 | GitHub 组织头像、apple-touch-icon 等需要满幅方图的平台 |
| `logo-circle.png` / `.webp` | 白圆 | 头像、社群图标 |
| `logo-rounded.png` | 白圆角方 | 应用图标 |
| `logo-hexagon.png` | 白圆角六边形 | 徽章、贴纸 |

方形位图边长 1024，字标位图宽 2048。字标的字母是画出来的路径，不依赖字体；字标里的图形以位图嵌入。

## 图形

云托着一只笑眯眯的南瓜，一道光环从云下绕过，右上角一颗星。云 = 云崽（Yunzai），南瓜 = NG（社区里读作「南瓜」）。

图形以一张白底位图为准，透明底版本由它抠出：图形里的几道白缝（南瓜瓣之间、云的内圈）是镂空的，
浅底上仍是白缝，深底上透出底色。带底的几种一律取白底，与原图一致。

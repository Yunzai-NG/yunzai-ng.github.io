# TermZero

远程执行插件：把 `rj` / `rjp` / `rc` / `rcp` / `sc` / `md` 六条命令交给主人，在机器人所在的机器上跑一段 JS、跑一条 Shell、看文件源码、把 Markdown 渲成图。

::: danger 权限最高的一组口子
六条命令**全部仅限主人**：任意 JS、任意 Shell、任意文件读取。装它即代表你清楚这层风险 —— 门禁全靠 `.master()`，路径不做越界限制。
:::

## 怎么装

插件市场装完即用（`setup.scripts: ["build"]`，装依赖与编译由内核代跑）。出图版（`rjp` / `rcp` / `sc` / `md`）依赖渲染器，没装时**自动回退纯文本**，不报错。

## 命令

触发词直接顶着内容写，中间空格可有可无：

| 命令 | 说明 | 例 |
|---|---|---|
| `rj<代码>` | 执行 JS，回**文本** | `rj 1+1` |
| `rjp<代码>` | 执行 JS，回**图**（带颜色） | `rjp process.version` |
| `rc<命令>` | 执行 Shell，回**文本** | `rc ls -al` |
| `rcp<命令>` | 执行 Shell，回**图** | `rcp git log --oneline -5` |
| `sc<路径>` | 看文件源码（带行号），回**图** | `sc ./package.json` |
| `sc起~止<路径>` | 只看指定行区间 | `sc10~40 ./src/index.ts` |
| `md<文件\|链接\|文本>` | 把 Markdown 渲成**图** | `md ./README.md` |

- **rj / rjp**：代码在带绑定的异步作用域里跑，可直接用 `e`（消息事件）、`ctx`（插件上下文）、`seg`（消息段构造器）、`logger`。顶层 `await` 与 `return` 都合法；单个表达式直接回显，求值抛的错会被抓住回给你看，不会被内核当成「命令崩了」。
- **rc / rcp**：经系统 shell 执行（Windows 走 PowerShell，其余走 `$SHELL` 或 `/bin/sh`），收回 stdout / stderr / 退出码；有超时（默认 60s），超时杀进程并回报。
- **sc**：给具体文件路径（相对路径按机器人工作目录解析），带区间只渲那几行、行号仍是真实行号；路径是目录则列目录内容；单文件最多 5000 行。
- **md**：参数按「`http(s)` 链接则下载 → 本地可读文件则读取 → 否则整段当原文」识别，故 `md # 直接写一段` 也能出图。

## 设计取舍

坚持**零第三方依赖**，故两处刻意做减法：`sc` 只认一个具体路径，不做「匹配多个文件回消息选序号」的交互挑选；没有语法高亮，`md` 自带一个覆盖常见语法的 Markdown→HTML 转换器（含 GFM 表格），ANSI 上色也是自带实现。要完整 CommonMark 或代码着色应另装渲染器插件。

一切进入 HTML 的文本先转义再着色，输出里的 `<script>` 只会「显示」不会执行；Markdown 链接只放行 `http(s)` 与相对路径，`javascript:` 一类被过滤成 `#`。

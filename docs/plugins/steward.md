# steward

指令运维：在聊天里重启实例、关机、更新插件与内核。**六条命令全部仅限主人。**

## 它做什么

把「更新已装插件」「更新内核」「重启 / 关机」交给主人，用聊天指令完成，不必登录机器。它借的是内核的 `ctx.app.maintenance`（受控地更新插件与请求重启 / 关机），刻意**不开放安装与删除** —— 市场能装任意 git 仓库等于任意代码执行，而「更新已装插件」是就地 `fetch` + `reset`，目标仓库早被信任过一次，两者信任边界不同。

## 怎么装

插件市场装完即用（需 core ≥ 0.6.3）。

## 命令

| 命令 | 作用 |
|---|---|
| `#重启`（`#重启内核` / `#重启实例`） | 优雅停机后由守护拉起 |
| `#关机`（`#停机` / `#关闭实例`） | 优雅停机且不再起来；执行前必先确认 |
| `#更新插件 [名字…]` | 更新指定插件并重载；不写名字则更新全部（本插件除外） |
| `#更新自己` | 更新本插件；更新后需重载或重启才生效 |
| `#更新内核`（`#升级内核`） | 经包管理器把内核升到目标版本，之后重启才生效 |
| `#运维状态` | 看这台实例能不能重启、关机，装了几个插件 |

## 重启与关机怎么生效

内核自己没有重启能力，它做的是「优雅停机」，**再把进程拉起来得靠守护**。CLI 0.6.0 起 `yzng start` [自带守护](/cli#自带进程守护)，裸起也能重启、关机；也可交给 pm2 / systemd。区别只在退出码：重启用 75，关机用 0。

- **重启**：探测到守护时直接动手；探测不到守护（`--no-supervise` 又没挂外部守护）时**先问一句确认** —— 那种实例停机后没人拉起。
- **关机**：无论如何**先问确认** —— 关掉之后没有任何聊天指令能把它开回来，只能到机器上手动启动。自带守护天然认得退出码 0；交给 pm2 要配 `stop_exit_codes: [0]`，`Restart=always` 的 systemd 要配 `RestartPreventExitStatus=0`。

`#重启` / `#更新内核` 重启完成后会回到原会话补一句，并**带上耗时**（「重启完成，耗时 12.35s」；内核更新则连版本变化一起报）。耗时从下达指令那一刻算到账号重新上线，故它含停机、被守护拉起、启动与账号重连的全过程，比单看进程启动时间更贴近体感。跨重启的回执存在 KV，由 `bot/online` 补发；超过 10 分钟的过期回执不再补发 —— 那多半是隔天被守护拉起，补一句只是噪声。

## `#更新插件` 会回什么

一次更新要拉代码、装依赖、跑编译，几十秒是常态，故分三步回话：

1. **收到就回一句**「正在更新 xxx，要拉取代码并编译，请稍候」。不回的话这几十秒里没有任何反馈，看着像命令没触发。
2. **每个插件更新完，紧接着发一个合并转发**，标题是「xxx 更新日志（N 条提交）」，其后每条一行 `[09-29 01:20] 提交信息`。折成卡片是因为一次更新几十条提交会把整屏刷满；平台不支持合并转发时退回逐条贴，只贴前 5 条加一句「另有 N 条」。日志紧跟各自那一个插件发、不攒到最后 —— 批量时攒在一起认不出谁是谁。
3. **最后一句汇总**，并说明接下来重载哪几个。重载完再报一句「已重载，新代码已生效」，失败的也照样回话。

拉取用的是 `--depth 1`，新提交的父链不在本地，故取日志前会先按上限（30 条）补拉一次历史。补拉或取日志失败都**不挡更新**，只退化成报最新一条、或不报日志。

### 编译不过就不重载

装依赖或编译失败时**不重载**，只回一句「xxx 不重载：编译失败：build：…」。理由是此时 `dist/` 还是旧的、或新代码 import 不到新依赖，换上去只会把一个跑不起来的插件顶替正在正常工作的那份。收拾好目录后到面板插件页手动重载即可。

## 更新为什么这样设计

- **市场认安装目录名，宿主认声明名**，两者常不同（`mhy-game` 装在 `mhy-game-plugin/`）—— 更新走目录名、重载走声明名，插件内部替你对上。
- **版本没变就不重启 / 不重载**：已是最新时升级命令照样成功，但跑的还是同一份代码。
- **`#更新内核` 判「变没变」看的是在跑的版本与磁盘上的新版本**，不拿两次磁盘读数比。磁盘上可能早已装好新内核、只是还没重启过，那时两次都读到新版本，会把「就差重启」误判成「版本未变」而跳过那次本该做的重启。
- **`#更新内核` 代跑 `yzng update`**，不自己重写升级逻辑（那条命令里攒着「只升 cli、其余由它带上来」等一串踩过才知道的判断）。

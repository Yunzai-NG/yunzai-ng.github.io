# webui-example

面板插件的示例包。四枚组件、一个页签、一份自带样式表、一份 node 侧、一项配置。

## 它做什么

它不解决任何实际问题 —— 它的用处是**照抄**。想写面板插件时，与其读五个真实插件再自己拼，不如从
这个包开始改：它把面板插件能用的每一样能力各示范一次，且每一处都短到能一眼读完。

四枚组件：

- **一言** —— 一整块居中的引言排版，左下角两枚图标按钮（换一句 / 复制）。
- **日历** —— 大日号、月历网格、农历与干支，其下是本年 / 本月 / 本周的剩余进度与距离春节。
- **时钟** —— 只报时刻，秒针每秒走一格。
- **跑马灯** —— 一行字横向滚动，示范包自带的那份 `style.css`。

外加一个插件页页签，列出本次会话取过的句子。

**日历与时钟刻意是两枚而不是一枚。** 报时每秒重画，而日历那些一天才变一次；合成一枚等于让月历
网格每秒重算一遍，且使用者也就没法只留其中一枚。

## 怎么装

在面板商店里装。它声明了一个依赖（农历用），商店会在包目录里代跑一次 `pnpm install` 装上它 ——
装不上也能用，只是日历那一枚会少几行农历与「距离春节」那一块。

本包没有构建步骤（node 侧入口就是源码），故索引里不声明 `setup`。

它有 node 侧，故装完**要重载一次 webui**。

## 它示范什么

| 能力 | 落在哪个文件 |
|---|---|
| 一个包给出多枚组件 | `index.js` 的 `export default [...]` |
| 插件自加页签 | `index.js` 的 `export const tabs` |
| 组件自己的交互（取数中 / 成功 / 失败三态） | `widgets/hitokoto.js` |
| 配置改完即生效 | `server/index.js` 每次现调 `ctx.config()` |
| 自带计时器要自己收 | `widgets/clock.js` 的 `api.onUnmounted` |
| 一枚组件何时该拆成两枚 | `widgets/clock.js` 与 `widgets/calendar.js` |
| 包带自己的依赖，且依赖装不上时不塌 | `server/index.js` 的农历 |
| node 侧代取外部接口（绕开 CORS） | `server/index.js` 的一言 |
| 自带样式表 + 容器查询 | `style.css` |

## 只有一项配置

**一言接口**（默认 `https://v1.hitokoto.cn`）。换成别家的接口或自建镜像都可以，留空按默认值算；
响应里的句子字段认 `hitokoto` / `text` / `content` / `sentence` 四种写法，故多数镜像直接就能用。

组件的样子不做成开关。一个示例包的价值在于源码好读，而每加一个「显示 / 不显示」的开关，读它的人
就要多分辨一次「这一段是为了什么」。

## 四处写的时候容易踩的

这四条都**不报语法错**，只表现为「写了没反应」—— 实测时它们各花了一次排查：

1. **node 侧默认导出的是含 `setup` 的对象，不是函数。** 写成 `export default function setup(ctx)`
   得到的是一句「node 侧入口须默认导出一个含 setup 的对象」，而那句话在 node 侧的日志里；浏览器
   那侧看到的是「`api.own` 说本包没有 node 侧」，隔得很远。
2. **`enum` 的候选项是 `{ value, label }` 而不是裸字符串**，且这类写错会让**整份**配置声明被拒 ——
   而表现只是「卡片上没有配置按钮」，不会有一句话告诉你是哪一项写坏了。
3. **组件的尺寸键叫 `defaultLayout`，不是 `layout`。**
4. **不要凭空自造 CSS 类名。** 没有自带样式表时，写一个不存在的类只会得到一行无样式的纯文本。
   面板现成可用的有 `.card`、`.stat`、`.hint`、`.err`、`.mono`、`.plain`、`.toolbar`、`.tag`、`.banner`。
   确实需要关键帧、伪元素或一个 7 列网格时，改为在 `package.json` 里声明 `webuiPanel.style` 自带
   一份 css。**但 `@keyframes` 的名字必须自加前缀**：选择器会被面板限定到本包，动画名却是全局的，
   两个包各写一段叫 `roll` 的动画时后注入的那份会盖掉前一份。

## 一处值得照抄的处置：上游失败不要冒成 500

一言取自第三方接口，而它会超时。若让那个错误抛出去，路由回 500 —— 而 500 的意思是「服务端有
bug」，别人的接口慢不是那件事，且它会污染每一份核对脚本的控制台断言。

做法是 node 侧把「第三方不给」当作一个正常的返回值（`{ error: "一言接口超时" }`），浏览器侧据此
显示一行小字并**保留上一句话** —— 一次网络失败把已显示的句子换成一行错误，等于「点一下就丢了
内容」。

## 另一处：格子有多宽与窗口有多宽是两件事

日历那一枚在窄格子里要把月历挪到事实之下，而它用的是 `@container (width < 300px)` 而不是媒体
查询。理由是使用者把这一格拖成 3 列宽时窗口仍是 1600px —— 按窗口宽度判断，那一格永远不会切换到
窄版排布。栅格里的每个格子都声明了 `container-type: inline-size`，故容器查询直接可用。

## 源码在哪

[Yunzai-NG/webui-example](https://github.com/Yunzai-NG/webui-example)

| 路径 | 内容 |
|---|---|
| `index.js` | 浏览器入口：四枚组件与一个页签 |
| `widgets/hitokoto.js` | 一言组件，含两枚图标按钮与三种状态 |
| `widgets/calendar.js` | 日历组件，月历网格与剩余进度 |
| `widgets/clock.js` | 时钟组件，每秒一拍且自己收表 |
| `widgets/marquee.js` | 跑马灯组件，示范包自带样式表怎么用 |
| `style.css` | 包自带的样式表，由 `webuiPanel.style` 声明 |
| `tabs/hitokoto-tab.js` | 插件页页签 |
| `server/index.js` | node 侧：一言代取与农历换算 |
| `package.json` 的 `webuiPanel` | node 侧入口路径、样式表路径与那一项配置声明 |
